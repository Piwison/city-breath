# 2.1 微縮城市方向：/prototype 指令

Piwi 在對話裡貼上下面這段來跑 `/prototype`（prototype skill 只能由使用者觸發）。依 2026-11-04 的遊戲手感建議改寫，規則細節見 `.claude/skills/diorama-game-juice/SKILL.md`。

```
/prototype 城市呼吸首頁的微縮城市方向（story 2.1）。以 design/prototypes/city-breath-flows.html 為基礎，讀 web/public/data/2026-09 的真實資料（districts.json、district-flows.json、stations.json），用 Three.js 做 3 個版本。先讀 .claude/skills/diorama-game-juice/SKILL.md 並照它的原型規則做。

技術：importmap 用 jsDelivr，three@0.186.1（含 three/addons 的 EffectComposer、UnrealBloomPass、OutputPass、Line2）、gsap@3.15.0、camera-controls@3.1.2。顏色只從 :root CSS 變數讀成 THREE.Color，JS 與 shader 不寫死色碼。

三版共用的遊戲機關：
1. 立體沙盤底座：行政區放在有厚度、斜切邊的底座上，不飄在空白背景。
2. 行政區呼吸：高度與發光隨當下小時的真實進出人數起伏；表面的小地標積木只是裝飾，高度不代表真實建築。
3. 脈衝流向與落點漣漪：弧線用 QuadraticBezierCurve3＋Line2 或 InstancedMesh 光膠囊，粗細與高度依人數；粒子一波波湧出（pow(fract(t*speed - progress + phase), 3.0)），早八、晚六更快；抵達時落點有一圈擴散漣漪。不用 1px 的 THREE.Line，不等速移動。
4. 點選聚焦：點行政區時用 gsap 彈起（elastic.out），其他區下沉變淡，鏡頭用 setLookAt 飛過去，只留這區的前 5 個「誰來」（暖色）與「去哪」（冷色）弧線，上方浮出區名與由真實數字決定的稱號（例如淨流入第一）。

三版差異：
A 晨昏微縮城：霧面玩具材質，太陽隨 24 小時繞行，有柔和陰影，深夜點亮窗光；流向是沿弧線一簇簇前進的小光膠囊。
B 夜光地景：深色戰術沙盤，局部 bloom，地塊邊緣發光；流向是會流動的發光光帶。
C 紙模型城市：淺色低多邊形紙工藝，疊層卡紙底座；日夜只靠一盞繞行的暖光與硬邊長投影；流向是紙緞帶，切換時用 back.out 像立體書彈起。

手機版面：首頁自動播放一天（48 秒，1x／2x，手指碰沙盤就暫停）；上方「找你的通勤」入口（選起站、迄站、時段，站對站），選完鏡頭飛到那條弧線並顯示同路人數與名次；下方時間軸附時段稱號；點行政區彈出「這區的人去哪、誰來」小卡（前 3 名排行，點排行項目鏡頭飛到該弧線）。HUD 不遮超過 35% 畫面。

規則：只顯示資料裡有的數字，不做擁擠度等資料沒有的指標；少於 10 人顯示「少於 10 人」；不用 emoji 當圖示；prefers-reduced-motion 時不自動播放、不搖晃鏡頭、彈跳改平滑，粒子改成依人數分級的靜態光帶，並提供手動「靜態模式」按鈕。
```
