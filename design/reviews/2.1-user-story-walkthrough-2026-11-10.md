# 2.1 原型對 user stories 的走查（2026-11-10）

對象：`design/prototypes/2.1-diorama/`（第四輪，天光）。依據：`_bmad-output/initiative-city-breath/user-stories-city-breath-2026-11-03/`。
方法：用手機尺寸（390×844）實際操作原型，逐條記下「從打開網頁到拿到答案」要做幾步、會卡在哪。主力族群 A、B、C 的 P0、P1 全部走過；D 以後只看 P0 與和主力重疊的。

## 走查前發現的共通問題（這輪已修）

| 問題 | 影響的 story | 修法 |
| --- | --- | --- |
| 小卡打開時會蓋住時間軸，要先關卡片才能換時段或平假日 | C2、E1、A4、B5 | 每張小卡加一列「‹ 時間 ›＋平日／假日」 |
| 找不到自己的車站：只能先點區、或放大地圖才點得到站 | A4、A7、C4、C5 | 上方入口改為「找車站／通勤」，面板多一顆「只看起站」 |
| 行政區只能看「這一小時」，不能回答「假日大家都去哪」 | E1、C2 | 行政區小卡加「這一小時／整天」 |
| 通勤卡看不到提早或延後的差別，要重新填一次 | A3 | 通勤卡加「早一點、晚一點出門呢？」三格，點了直接換 |
| 大日子只列有原因的活動，異常但沒查到原因的日子看不到 | C3、G2、I3 | 清單分「查到原因的」與「原因未查證」，全城異常日也列（例如 9/25 全城只有平常的 0.64 倍） |
| 活動卡只有到場高峰，看不出散場往哪站走、幾點退潮 | B1、B5、G1 | 活動卡加整天曲線（短橫線是平常）、散場高峰時周邊 5 站的進站人數與倍數、「多了 N 人」 |
| 車站卡只有前 3 站，看不出去哪幾區，也看不出這站是什麼性格 | A4、C4、C5 | 前 5 站＋「去哪幾區」加總＋「這一站的個性」（全線排名前 20 的特質） |
| 環狀線乘客不知道為什麼迄站選單裡沒有自己的站 | A7 | 面板直接寫明環狀線沒有出站紀錄 |
| 第一次打開不知道能點什麼 | 全部 | 首次開啟提示「點一個區、一個地標或發光的寶石看看」（只出現一次） |

## 結論與建議

1. 三大族群的 P0 裡，唯一還做不到的是「分享」（A2、B2 的截圖、C6）。建議下一張實作的票先做 3.3 分享卡，三個 P0 一起解。
2. 需要新資料或新計算、要請 Sofia 開票的：每站「誰來這站」的來源（D1、F2，也讓 C5 更完整）、活動日逐日起訖（B3）、路網距離（A5、D3、H1）。
3. 正式版注意：車站選單要能打字搜尋；地形、地標、班距要改成管線輸出（AD-1）。
