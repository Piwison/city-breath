# 3.24 首頁減法：三條路（原型）

`index.html` 是單一檔案（圖片、樣式、程式都在裡面），手機直接開；寬螢幕會在中間放一個 390×844 的手機框，右邊有這一版的說明。最上面一排切換 A／B／C（記在這個瀏覽器），旁邊「模擬：動過鏡頭」等於拖過鏡頭或選了區、站、流向，按了「回到全景」才會出現。

背景是建置版首頁的真實截圖（2026-09 資料、平日與假日的 7、8、18、22 點，390×844、隱藏原本的 HUD）；播放時每 3 秒換一小時、交叉淡入，模擬背景自動播放。時間旁的月份日型（例如「9 月平日平均・早晨通勤尖峰」）、圖例數字、搜尋清單的站名與分組，都是從建置版畫面讀出來的，沒有手寫數字。搭乘畫面用 8.6 的截圖（`design/reviews/8.6-ride-bannan/09-…`），是靜態的。

三個版本共同點：沒動過時畫面上只有「搭板南線」、「找你的站」、播放鈕、時間軸（時間＋月份日型、平日／假日）與「⋯更多」。分享這一刻、圖層、1x、靜態、回到全景、時間軸下方兩行說明都不在首頁。「⋯更多」裡依序是分享這一刻、圖層、播放速度、靜態模式、怎麼看這張圖、關於；**最後兩項標著「待你確認」**。

## A　上下疊

- 「搭板南線」寬滿版、高 56px 的主按鈕；下面是小膠囊「找你的站」；再下面是時間軸，大小照現在（只拿掉 1x、靜態與兩行說明）。
- 「⋯更多」放在時間軸右下角（原本 1x、靜態的位置），按了從下緣浮起面板。
- 「回到全景」出現在「找你的站」右邊（不放上方：拇指夠得到，HUD 高度也不增加）。
- HUD 約占畫面 28%。改動最小，但三個版本裡最高。

## B　一大一小並排＋角落選單

- 「搭板南線」（寬）與「找你的站」（窄）並排一列。
- 「⋯更多」是右上角的圓鈕，打開小選單；「回到全景」出現在它左邊。
- 背景播放時時間軸收成一條：播放鈕、時間、「9 月平日平均」、平日／假日，加一條細的一天進度；點時間展開完整拖曳條，按 ⌄ 收回；暫停時一律展開。
- HUD 收起時約 21%，展開約 28%。缺點：收起時要多點一下才能拖時間。

## C　一個底座（我的提案）

- 三條路裝在同一張玻璃底座：上半是③看城市呼吸（播放、時間與月份日型、平日／假日、細拖曳條），下排是「找你的站｜搭板南線｜⋯更多」，最大的「搭板南線」在中間、拇指正下方。
- 按「⋯」，底座就地翻成更多清單（不另開一層、不蓋住別的東西），再按一次翻回來。
- 「回到全景」貼在底座右上角。
- HUD 約占 21%。

為什麼這樣排（體驗原則 9、10）：

1. **首頁只有一個地方要看。** 三條路都在同一塊底座，像遊戲的底座 HUD：狀態（時間）在上、動作（三顆按鈕）在下，眼睛不用在畫面上下跑。
2. **大小就是主次。** 主要的路最大、在正中間；次要的路與「更多」一樣小、分在兩側，不用靠文字說明哪個重要。
3. **上方完全留給場景。** 先玩：沒動過時，畫面上半部沒有任何按鈕；「回到全景」也貼著底座出現，不另外佔上方一排。
4. **「更多」不疊新一層。** 點開、關掉都在同一個位置，關掉就回到原樣；不會出現面板蓋面板。
5. 代價：拖曳條比現在細（看得到 10px、點得到 36px），時間刻度拿掉了，只留停駛斜紋。

## 可以試的

- 播放／暫停、平日／假日、拖時間軸（會跳到最近的截圖時刻）；點場景＝手指碰到沙盤，會暫停。
- 「⋯更多」：分享這一刻（只有複製連結）、圖層（開關不改畫面）、播放速度 1x／2x、靜態模式（停在 8 點）、怎麼看這張圖（展開文字圖例）、關於（「3.17 會補」）。
- 「搭板南線」→ 搭乘畫面（暫停／下一站／下車）→「下車」→「在台北車站下車」與「分享」→ 分享面板只有「複製連結」→「回到首頁」。
- 「找你的站」→ 搜尋面板（可打字篩選）→ 點一站：出現車站卡的位置示意，「回到全景」也跟著出現。
- 減少動態：不自動播放、停在 8 點；面板、選單、交叉淡入都直接切換。

## 原型裡自己決定的（Piwi 可推翻）

- A 的「回到全景」放在「找你的站」右邊，不放右上角；B 放右上角「⋯」左邊；C 貼在底座右上角。
- B 的時間軸：暫停時一律展開，播放中收成一條；展開後要自己按 ⌄ 收回或暫停再播放。
- 「⋯更多」的順序照票面寫的順序；3.17 的票面寫「關於」放第一項，到時再調。
- 搭乘結束先出一張小卡（「在台北車站下車」＋分享＋回到首頁），按分享才開分享面板，面板裡只有「複製連結」。
- 播放中只換 4 個時刻的截圖（7、8、18、22 點），不是一整天。
- 「怎麼看這張圖」裡的圖例數字是那一小時、全城視角的值（建置版時間軸下方原本顯示的內容）。
