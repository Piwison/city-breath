# 2.1 微縮城市方向原型

## 第三輪（2026-11-05）：新北、車站視角、精緻度與遊戲感

Piwi 對第二輪的回饋：捷運包含新北市要補上；只能看區、看不到個別車站；建築太小太雜、不夠精緻，要更有遊戲感。三個版本（天光、調色、移軸）仍只差日夜光影，以下改動共用：

- 新北：河川加上新北市政府水利局地圖服務的中央管河川與市管河川（淡水河、大漢溪、新店溪、基隆河、景美溪、二重疏洪道），21 區都有河。公園綠地仍只有臺北市（新北的公園清單只有地址、沒有範圍）。板南線頂埔段路網圖缺漏，以直線連到頂埔站（`layers.json` 的 `approxTrack`）。
- 車站視角：每站是「廣場＋細柱＋站珠」，站珠是路線色、柱高依該站此刻進出人數。放大到一定程度或選了行政區才點得到車站、才顯示站名（只標重要的，避免一片字）。點站後鏡頭飛過去、站珠彈一下，下方小卡有進站、出站、平日全日進出、一整天的長條（點長條跳到那個時段）、這一小時最常去的 3 站（點了飛到那條線），並可「從這站找通勤」。地圖上畫出這站到前 5 個目的地的站對站緞帶（od 分片，線寬同一套比例）。行政區小卡也列出這區此刻最忙的 6 站。
- 街廓建築：整座城共用一張方格，每 4 格留一條大街；每格依附近車站的全日人數算疏密，密的地方蓋高、疏的蓋矮、山區成片種樹、公園種樹、車站周圍留廣場、河上不蓋。建築是矮胖的圓角積木（最高約 1.8），三種牆色，高樓頂上有磚紅、灰綠、沙金的小塔點綴；窗戶用世界座標畫，樓層大小一致，入夜亮燈、深夜漸少。整區街廓高度隨該區此刻人數起伏。地標（示意）：台北 101、圓山大飯店、中正紀念堂。
- 列車（示意）：沿真實軌道雙向跑，同線列車的間隔依臺北捷運公司公告的發車班距（尖峰較密），營運時間外沒有列車；環狀線不在班距資料裡，不畫。
- 遊戲感：按下地塊時微微壓扁、放開彈回；點中處泛起漣漪，Android 輕震；選區、選站、點流向時緞帶從起點畫出去（整點更新不重畫）；播放中跨進新時段，上方浮出時段名稱；名牌彈出；雲在白天飄過並投影，放大時淡出。減少動態時以上全部關掉或改成平滑過渡。
- 底座改成三層「地層」蛋糕。

研究與取捨記在 Piwi 的回覆裡（為什麼上一輪看起來廉價：太小、太多、隨機旋轉、沒有層次、沒有焦點、沒有次要動態、點了沒反應）。

效能：建築用一段圓角（每棟約 100 個三角形），所有重複物件都是 InstancedMesh。還沒在中階 Android 實測（AD-6：30 fps）。

## 第二輪（2026-11-05）：從「晨昏」延伸

第一輪三個方向（晨昏、夜光、紙藝），Piwi 選了晨昏，提出四點：日夜光亮沒變、要能切換疊圖（捷運圖、城市建築）、看不出線寬代表的流量、找更好的設計。第二輪三個版本共用下面這些改動，只差日夜光影的做法：

| | 天光（`?v=1`） | 調色（`?v=2`） | 移軸（`?v=3`） |
| --- | --- | --- | --- |
| 日夜怎麼變 | 材質固定，只有光在變：太陽東升西落、陰影跟著轉，夜裡換月光 | 每個時段一組配色＋畫面調色（lift/gain、飽和度、暗角），三階卡通光 | 跟天光一樣真實打光，再加上下景深模糊，像拍真的模型 |
| 夜晚 | 窗光、站燈、捷運線在暗地上發亮 | 夜裡窗光與流向帶 bloom 光暈 | 城市燈光微微暈開 |
| 鏡頭 | 一般俯角 | 一般俯角 | 低一點的鏡頭 |
| 代價 | 最省效能 | 多一道後製 | 多三道後製，畫面上下會糊 |

共用改動：

- 天空：沙盤後面是依時刻內插的天色、太陽與月亮、夜裡的星星；第一輪那一大片地面擋住了天空，所以看不出日夜，已經拿掉。時間軸的底色就是一天的天色。HUD 入夜後換成暗色。
- 自動播放從清晨 5 點多開始，前幾秒就會看到日出（第一輪從早上 8 點開始，前 16 秒都是白天）。減少動態時不播放，停在早上 8 點，拖時間軸一樣會換日夜。
- 地塊改成固定厚度的薄片，疊圖才放得上去。「呼吸」改由建築高度（整區依當下進出人數起伏）和車站高度（每站依當下進出人數）表現。
- 圖層（右上角）：流向、捷運路線、車站、河川、公園綠地、建築、區名，都可以開關。點選行政區時，這區的河川、綠地、路線、建築跟著一起彈起。
- 線寬：和人數成正比（`W_MIN + (W_MAX − W_MIN) × 人數 ÷ 當月最大流向`），尾端放大的箭頭，緞帶上的箭紋往目的地捲動。時間軸下方的圖例用同一個公式、依目前鏡頭換算像素，所以圖例的粗細和畫面上一樣。一顆光點代表固定人數（預設 50 人，超過同時 2,600 顆的上限會自動加倍，圖例跟著改）。
- 流向少一點：全市只畫前 12 大（第一輪 28 條），選了區畫這區前 5 去哪、前 5 誰來。前三大在弧頂標人數，重疊時自動挪開。點緞帶會出現這條流向的小卡（人數、全市第幾名）。

## 疊圖資料

`layers.json` 由 `tools/build_layers.py` 產生，依 21 個行政區切開。來源都是 data.taipei，授權為政府資料開放授權條款第 1 版：

- 捷運路線：臺北都會區大眾捷運系統路網圖（臺北市政府捷運局）；路線色碼：臺北捷運路線資料服務。環狀線不在臺北捷運的路線資料裡，暫用黃色。信義線東延段興建中，未畫。
- 河川：臺北市河流（河川用地，臺北市政府工務局水利處）；新北市政府水利局地圖服務的中央管河川、市管河川（第三輪加入；這個服務沒有標示開放授權，正式版改用水利署「河川河道」開放資料，data.gov.tw 25781）。
- 公園綠地：臺北市水綠地圖集的公園、河濱高灘地（臺北市政府工務局）。
- 列車間隔：臺北捷運路線發車班距頻率資料服務（第三輪加入）。

限制：

- 公園綠地只有臺北市資料。
- 建築是示意：位置貼近真實車站、數量依該區全日人數、高度依該區當下人數，不是真實建物。國土測繪中心的建物圖層（WFS `EMAP_BUILD`）要另外申請授權；臺北市的建照套繪圖只有約一萬筆建照，不代表全市。
- 正式版要改成管線輸出（AD-1）並經 `projection.ts` 的 `project()` 轉換（AD-12），需要另開 story。

## 怎麼開

在 repo 根目錄起本機伺服器：

```bash
python3 -m http.server 8765
# http://localhost:8765/design/prototypes/2.1-diorama/index.html?v=1
```

數字鍵 1–3 或左右方向鍵切換版本，R 重播進場。資料直接讀 `web/public/data/2026-09/`。

重建疊圖（原始檔下載方式見腳本開頭）：

```bash
python3 -I design/prototypes/2.1-diorama/tools/build_layers.py <原始檔資料夾> . design/prototypes/2.1-diorama/layers.json
```

Piwi 選定後依 prototype skill 的規則，把選中的版本移進 `web/src/scene/`（2.2、2.3），這個資料夾刪除。
