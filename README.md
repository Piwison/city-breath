# 城市呼吸｜北捷人流脈搏

台北人每天從哪裡來、往哪裡去，以及這跟你有什麼關係。資料：[臺北捷運每日分時各站 OD 流量](https://data.gov.tw/dataset/128506)（政府資料開放授權條款第 1 版）。

- `pipeline/`：把每月約 300 MB 的 OD 檔彙總成約 3 MB 的靜態 JSON（DuckDB）
- `web/`：React + MapLibre + deck.gl 靜態網站
- 開發規範與指令見 [CLAUDE.md](CLAUDE.md)，資料格式見 [docs/data-contract.md](docs/data-contract.md)

## 2026-09 資料驗證結果

| 項目 | 結果 |
| --- | --- |
| 列數／檔案大小 | 8,240,400 列、302 MB；DuckDB 讀取 1.3 秒、完整彙總 8 秒 |
| 跨月日期 | 9 月檔沒有混入其他月份（管線仍會過濾） |
| 營運時段 | 0、1、5–23 點；2–4 點無資料 |
| 車站 | 進站 120 站、出站 109 站 |
| 環狀線 | 11 站只出現在進站欄位（出站未入檔） |
| 站名不一致 | 迄站有 O景安、G大坪林、O頭前庄 前綴；「大橋頭站」多一個字 |
| 平日均量 | 約 214 萬人次／日，與市府統計（210.2 萬）相符 |
| 假日 | 9/25 中秋、9/28 教師節日量約平日 65–70%，資料本身就看得出來 |
| 車站類型 | 固定 4 型（2025-10～2026-09 共 12 個月合併 k-means，silhouette 0.30；AD-27）：臥室站 32、住商站 27、人氣站 30、辦公站 20 站（各站整年最常歸到的型），94／109 站 12 個月都同一型；名稱由 Piwi 定 |
